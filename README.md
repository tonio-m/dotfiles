# ~/.claude

My Claude Code config, versioned at https://github.com/tonio-m/dotfiles on the `claude` branch.

The repo is public, so `.gitignore` is an allowlist: only my own instructions, skills, workflow files and scheduled tasks go in. Credentials, transcripts (`projects/`), memory, history, plugin caches and `settings.json` (it names internal hosts) stay out. To version something new, add it to `.gitignore` and check it for secrets and client names first.
